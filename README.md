# LifeCity

مشروع لعبة عالم مفتوح ثلاثية الأبعاد للهاتف.

## الرؤية
مدينة حية فيها لاعب، سكان مستقلون، سيارات، وظائف، اقتصاد، مهام، علاقات، ليل ونهار، طقس وحفظ للتقدم.

## مراحل التطوير
1. النواة واللاعب والتحكم باللمس.
2. المدينة والـNPCs والذكاء السلوكي.
3. السيارات والقيادة.
4. الوظائف والاقتصاد والمهام.
5. الحوار والذاكرة والعلاقات.
6. الرسومات والأصوات والتحسين للأندرويد.
7. اختبارات وبناء APK.

> هذا المستودع هو مصدر المشروع. لن نعتبر اللعبة مكتملة حتى يتم بناء نسخة Android واختبارها فعليًا.
