# LifeCity 3D First Playable

This folder defines the first playable 3D milestone: a third-person character in a small connected test city with mobile-friendly controls, a drivable placeholder vehicle, pedestrians, a mountain route and Shadow Cave entrance.

The project is designed for Godot 4. A real APK still requires Godot/Android build tooling and 3D assets; these source files are not themselves an APK.
